Element Identification Pipeline (LIBS + Synthetic Data + NN)

This project generates synthetic LIBS spectra from configurable sample compositions, builds element weight spectra over TE/NE conditions, and trains a neural network to predict element presence/concentration from spectra.

Input
Measured spectra + calibration wavelength
Generator
SyntheticLIBSDataset (multiprocessing)
Features
Spectra x multi-weights (matrix product)
Model
Projection + Hidden FC + Sigmoid outputs

Graphical Workflow

High-level data flow from source configuration to final prediction.

1) Data & Sample Definition

  • `read_sample_types.py` loads `Samples_Fe_matrix.xlsx` (Concentrations + Uncertainties).
  • Builds `SAMPLE_TYPES` with concentration ranges.
  • Loads wavelengths from measured JSON using `get_spectra`.

2) Synthetic/Weight Spectrum Generation

  • `Sample_bootstrap.py`: random composition + Te/Ne -> synthetic spectra.
  • `weight_generator.py`: per-element spectra across TE/NE grid.
  • Saves `multi_weights_vacuum.h5` and legacy `element_weights.h5`.

3) Training & Inference

  • `train_nn.py`: features = spectra @ weights.T.
  • Trainable projection: 7700 -> 77, then hidden layer and output.
  • `predict_nn.py`: preprocess input H5, predict per-element probabilities.
